# Основы веб-программирования — Баженов А. П., гр. 3412

## Структура

```
ОСНОВЫ ВЕБ ПР/
├── index.html            главная: список всех лабораторных
├── ЛАБ1_ВЕБ_ОТЧЕТ.docx   ЛР1 (git)
├── ЛР2/                  ЛР2. HTML, CSS
│   ├── index.html        меню заданий ЛР2
│   ├── student.html      2.1 страница о студенте
│   ├── tables.html       2.2 таблицы А и Б
│   ├── forms.html        2.3 формы А и Б
│   ├── css.html          3   CSS: inline, <style>, внешний файл
│   ├── style.css         3   внешняя таблица стилей
│   └── img/photo.png     фото для 2.1
└── .vscode/              задачи и настройки VS Code
```

## Как показать на паре

1. VS Code → **File → Open Folder** → `ОСНОВЫ ВЕБ ПР`.
2. **Ctrl+Shift+B**: в браузере откроется главная страница, дальше переходишь по ссылкам.

Другие варианты:

- **Ctrl+Shift+P → Tasks: Run Task**, затем:
  - «ЛР2: открыть меню заданий»;
  - «Открыть текущий файл в браузере» — открывает файл, который сейчас открыт в редакторе.
- **Live Server**: VS Code предложит поставить расширение. После установки нажми **Go Live** в правом нижнем углу. Страница будет сама обновляться при сохранении файла, удобно, если преподаватель просит что-то поменять на ходу.
- Без VS Code: двойной щелчок по `index.html` в проводнике.

## Где что показывать

| Задание | Файл | Что сказать |
|---|---|---|
| 2.1 | `ЛР2/student.html` | разные теги: заголовки, списки `ul/ol/dl`, таблица, `img`, `a` (ссылка, якорь, mailto), `abbr`, `blockquote`, `sup/sub`, `details` |
